# Employee Management System

## 1. Project Description

The Employee Management System is a full-stack web application developed using Python Flask, HTML, CSS, JavaScript, and SQLite.

The main purpose of this project is to simplify employee record management through two separate login portals: Admin and Employee.

The Admin can manage employee records, while employees can securely access their personal information through their individual accounts.

## 2. Objectives

- To simplify employee record management.
- To provide separate Admin and Employee login portals.
- To maintain employee information digitally.
- To provide secure authentication.
- To reduce manual record-keeping.
- To make employee management simple and efficient.

## 7. Steps to Run the Project

**Step 1: Open the Project**

Open the project folder in Visual Studio Code.

**Step 2: Open Terminal**

Select Terminal → New Terminal.

**Step 3: Install Required Packages**

```bash
pip install -r requirements.txt
```

**Step 4: Start the Application**

```bash
python app.py
```

**Step 5: Open the Application**

Open your browser and enter:

```text
http://127.0.0.1:5000
```

## 8. Login System

The application provides two separate login portals:

**Admin Login:**
- Admin can access all employee management features.
- Admin can add, edit, view, and delete employee records.

**Employee Login:**
- Each employee has an individual login account.
- Employees can access only their permitted personal information.

Default Admin Credentials: Refer to the credentials generated by the application during initial setup.

## 9. Database Management

SQLite is used to store employee information and login credentials.

The database manages:
- Admin account details.
- Employee account details.
- Employee personal information.
- Department information.
- Attendance records.

Passwords are stored using secure password hashing.
